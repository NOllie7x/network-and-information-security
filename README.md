# 网络信息安全学习资料

整理了网络安全课程实验资料，包含实验说明、初学者学习指南和实验分析文档，方便按实验顺序学习、准备操作与复习。

### 如何使用

1. **先看实验说明**：了解实验目的、任务要求和实验环境。
2. **再看初学者学习指南**：建立相关概念，理解工具和技术原理。
3. **操作前参考实验分析**：快速梳理实验流程、关键步骤与注意事项。
4. **完成后整理实验结果**：根据实际操作记录过程、截图、现象与结论。

### 文档说明

* **初学者学习指南**：侧重背景知识、基本概念和原理解释。
* **实验简明分析**：侧重实验目标、总体思路和容易忽略的事项。
* **实验详细分析**：侧重操作逻辑、关键命令及其背后的技术原理。
* **实验说明**：以课程提供的原始要求为准。

### 使用提醒

* 不同操作系统、软件版本和实验环境可能导致界面或命令有所差异，请以实际环境为准。
* 文档中的 IP 地址、账户、密码和配置仅作示例时，不应直接用于真实网络或生产环境。
* 涉及端口扫描、账户管理、远程连接和流量捕获的操作，只能在自己拥有或明确获准的隔离实验环境中进行。
* 实验报告应如实记录实际操作和观察结果，不要将示例步骤或预期结果写成已经完成的实验结果。
